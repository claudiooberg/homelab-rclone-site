Privacy Policy.

Home Lab Rclone Backup
Last updated: November 22, 2026

01 / Overview

Home Lab Rclone Backup is a personal, non-commercial application used to store encrypted backups in Google Drive. It is not offered as a public service.

02 / Google Drive Access

The application uses the Google Drive API with the drive.file OAuth scope. This permission limits access to files created or explicitly authorized for use with the application.

03 / Data Processing

Backup data is encrypted locally using Restic before being transferred to Google Drive through Rclone.

The application does not intentionally collect analytics, advertising identifiers, or tracking information.

04 / Data Storage

Encrypted backup files are stored in the authorized user's Google Drive account. The application does not operate an independent cloud storage service.

05 / Data Sharing

The application does not sell or share user data with advertisers or data brokers. Google Drive is used solely as the authorized backup storage provider.

06 / Access & Revocation

The authorized user can revoke the application's Google Drive access through their Google Account's third-party connections settings.

Backup files can be deleted directly from Google Drive by the account owner. Revoking access does not automatically delete existing backups.

07 / Contact

This application is maintained for personal use. Questions about its privacy practices can be directed through the project's GitHub repository .
